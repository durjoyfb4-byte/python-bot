# Telegram Automation Test Lab Bot

A fully automated Telegram bot for testing, learning, and development purposes.

## Features

- 🧪 9 Different Test Types
- 📊 Real-time Analytics
- ⏰ Automated Scheduler (4 jobs)
- 🔔 Notification System
- 👤 User Registration
- 🛡️ Rate Limiting
- 📝 Detailed Logging

## Deployment on Render

1. Create account on render.com
2. Connect GitHub repository
3. Add environment variables:
   - BOT_TOKEN
   - OWNER_ID
4. Deploy!

## Local Development

```bash
pip install -r requirements.txt
python bot.py
